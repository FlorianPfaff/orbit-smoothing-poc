Separate engineering experiment · 19 October 2026

Less repeated interpolation, identical nuisance solutions

All 12 fixed-orbit GNSS nuisance profiles completed with strict nuisance convergence. All six cache-off/on pairs matched on all 97 scientific artifacts per pair. The 106 native tests and 51 correction regressions passed without failures or skips.

Bounded result. These are measurements from the same candidate executable with an optional interpolation cache toggled. The cache remains off by default. This result does not establish whole-orbit convergence, authorize covariance, replace frozen benchmark attempts, or certify a v4 release.

What changed and why

The first frozen 24-hour dense fit timed out after 7,200.426 s. Its two completed fixed-state nuisance profiles consumed 7,057.355 s (98.013%); the tighter-closure profile was unfinished and no LM trial was evidenced. This identified a profiling bottleneck, without identifying every internal cost. The failure and incomplete measurements are preserved.

The isolated candidate reuses an exactly keyed dynamic interpolation result only within a native row-building generation. It still executes the original per-observation GNSS design, local QR, priors, residual arithmetic, and objective replay. New generations invalidate cached values. It does not introduce nuisance warm starts or reuse stale factors. Physical models, weights, thresholds and compatibility defaults are unchanged.

Exact equality and convergence scope

Each pair verifies all generations through a fresh final undamped factor: weighted rows, R and right-hand-side payloads, nuisance/dynamic coordinate exports, updates, receiver times, singular values, profiles, rank/factor diagnostics, prior/residual costs, support and line-search decisions. Text and binary payloads compare byte for byte; JSON scientific values compare exactly. Only the declared child user CPU, system CPU and peak RSS fields in line-search trials are removed. The full comparison inventories and hashes are linked in the table.

All twelve runs made six nuisance iterations and satisfied the unchanged 10−8 m threshold for two consecutive updates. No run used a floor-limited pass. Equality of a floor-limited result would remain progress-only evidence and could not authorize covariance. Fixed-orbit nuisance convergence does not establish dynamic LM convergence, and these runs produce no accepted orbit covariance. The complete propagation/refinement/objective suite was not repeated here.

Failures, audits and campaign preservation

The first build controller failed because it assumed an optional header had been copied into the native tree. Its replacement fixed that control assumption, with no numerical source change. The first analysis-tool review rejected command-shape and receipt/counter attribution defects. Those counterexamples and the rejected review remain published beside the corrected 77-test independent review. No unsuccessful attempt was silently replaced.

The independent actual-results audit is published with the real execution evidence. The native/regression run adds 157 passing tests; the separate native patch/control focused tests report 18 passing checks. These are distinct validation scopes. All execution receipts report return code zero and verified owned-process cleanup; a successful process alone was not treated as scientific convergence.

The read-only snapshot at 06:15 UTC found the original frozen campaign driver alive with matching identity and no process-visibility errors. It retained two timed-out attempts and was running the first family’s segmented_4h attempt. That snapshot is historical evidence, not a continuing liveness claim. The campaign’s executables, settings and attempts remain separate from this candidate.
