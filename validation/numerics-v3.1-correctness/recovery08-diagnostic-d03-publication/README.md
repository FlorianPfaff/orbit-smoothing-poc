# D03 presentation provenance

These receipts independently verify the separate [analyses01–03 snapshot](../recovery08-diagnostic-d03/index.html) and [analysis04 appendix](../recovery08-diagnostic-d03-analysis04/index.html). They do not authorize scientific acceptance, covariance or a release. The source, runtime and failed execution08 gates are unchanged.

The initial analysis04 publication preflight rejected a manually mistyped expected receipt digest before creating output. The exact original receipt remained intact. The appendix was subsequently clarified to define each component contribution; the previous draft manifest is retained here. Both final packages passed independent stored/expanded byte and interpretation reviews.

Presentation scripts are path-tokenized archival copies of one-off assemblers. They verify original artifacts in the private run layout; tokenized paths must be mapped to a locally verified artifact layout before replay. The executed diagnostic controls and analyzer sources are preserved separately in each package. Raw traces, native binaries, full source trees and the external clock cache are not included.
